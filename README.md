# Hey, I'm fastdelta50731

I spend most of my time writing Python scripts that make repetitive tasks disappear. Whether it's batch-processing files, scraping public data, or wiring up small tools that talk to each other, automation is the part of coding I enjoy the most.

## What I care about

- **Python** – My go-to language for almost everything. Clean scripts, solid packaging with pip, and the occasional notebook when I need to explore data quickly.
- **Automation** – Turning multi-step manual work into something that runs on a schedule or with a single command. Cron jobs, systemd timers, and simple CLI wrappers are regular tools in the box.
- **Linux** – I live in the terminal. Shell scripting, package management, and understanding how processes and filesystems behave under the hood keep me productive.
- **Open Source** – I prefer reading and contributing to projects that are public. Small bug fixes, documentation improvements, and sharing utility scripts all count.

## Daily setup

Most days start with a terminal open on a Linux machine. I keep a collection of small Python utilities for renaming batches of files, generating reports from CSVs, and keeping local backups tidy. When something needs to run unattended I wrap it in a systemd service or a simple cron entry and forget about it until the logs need checking.

I also like keeping configuration in plain text—dotfiles, shell aliases, and small Makefiles—so everything stays version-controlled and easy to move between machines.

## A few principles

Write the smallest script that solves the problem. Prefer readable code over clever one-liners. Document the non-obvious parts so future-me (or anyone else) can understand it six months later. And always leave the system cleaner than I found it.

If you maintain an open-source project that involves Python tooling, Linux utilities, or automation helpers, feel free to open an issue or drop a note. I'm happy to take a look at small contributions or just swap ideas about better ways to automate everyday work.

Thanks for stopping by.
